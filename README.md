# CRUD Simples em PHP e MySQL

Este projeto é um **CRUD básico (Create, Read, Update, Delete)** desenvolvido em **PHP**, utilizando **MySQL** como banco de dados e **Bootstrap 5** para o layout.

O objetivo do projeto é praticar os conceitos fundamentais de desenvolvimento web com PHP, incluindo formulários, conexão com banco de dados e manipulação de registros.

---

## 🛠️ Tecnologias Utilizadas

- PHP
- MySQL
- Bootstrap 5
- HTML5
- CSS3
- JavaScript
